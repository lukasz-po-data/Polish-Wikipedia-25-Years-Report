# WIKIPEDIA

Power BI report prepared for the contest organized by #BI_NGO (Business Inteligence for NGO) and Wikimedia Polska to commemorate 25th anniversary of Polish Wikipedia.

**Report link:** [25 Years of Wikipedia](https://app.powerbi.com/view?r=eyJrIjoiZTFlZGJlNGMtNDMzMy00MWE3LTk2NDktMjRmMzFjNDg1NWNjIiwidCI6ImQwMzYzN2RmLTdiM2EtNDU2NC04NzBiLTA2MjJhODFhNzY0ZCJ9)

As it was all about Wikipedia Poland, the report itself was also prepared in Polish. Data for the report was partially provided by the organizers, partially extracted from Wikistats.
